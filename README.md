# جسر الحرير — Silk Bridge

موقع + أداة عمل لوسيط إنتاج التسويق: العميل يرسل طلبه، وأنت تطلع له عرض سعر مرتب
بهامش ربح واضح، وتبني منه قائمة الشراء من الموردين وتتابع الصرف الفعلي.

الموقع كامل بصفحة واحدة، بدون سيرفر وبدون قاعدة بيانات — يشتغل من أي متصفح.

---

## التشغيل

**محلياً:** افتح `index.html` بالمتصفح. خلاص.

**على الإنترنت (مجاناً عبر GitHub Pages):**
في المستودع → `Settings` → `Pages` → اختر الفرع (`main`) والمجلد `/ (root)` → حفظ.
بيصير عندك رابط مثل `https://<username>.github.io/badges/`.

**نسخة بملف واحد** (ترسلها بالواتساب أو تشتغل أوفلاين):

```bash
python3 tools/build_single.py     # ينتج dist/jisr-alhareer.html
```

## أقسام الموقع

| القسم | الرابط | لمين |
|---|---|---|
| الرئيسية | `#/` | العميل — تعريف بالخدمة وطريقة العمل |
| الخدمات | `#/services` | العميل — دليل الأقسام والأصناف |
| اطلب عرض سعر | `#/request` | العميل — نموذج الطلب |
| مساحة العمل | `#/app` | أنت — محمية برمز دخول |

رمز الدخول الافتراضي **1234** — غيّره من الإعدادات أول ما تدخل.
(الرمز حماية بسيطة تمنع الفضول، مو حماية أمنية — لا تحط فيه أسرار حساسة.)

## دورة العمل

```
طلب العميل  →  عرض سعر  →  اعتماد  →  قائمة شراء  →  متابعة الصرف والربح الفعلي
```

1. **الطلبات** — كل طلب يوصل من النموذج يظهر هنا برقم مرجعي (`RQ-2609-001`).
   تقدر كمان تسجل طلب يدوي إذا أحد كلمك على الجوال.
2. **حوّل لعرض سعر** — بضغطة زر: بنود الطلب تنتقل للعرض، والتكاليف والهوامش
   تتعبى تلقائياً من الكتالوج إذا الصنف مسجل عندك.
3. **بناء العرض** — تكتب تكلفة المورد + هامشك %، وسعر البيع يُحسب لحظياً.
   تقدر تضيف رسوم خدمة (نسبة أو مبلغ)، شحن، خصم، وضريبة القيمة المضافة.
   الملخص المالي يوريك **تكلفتك، ربحك، ونسبة الربح** — وهذي أرقام ما تظهر للعميل.
4. **تسليم العرض** — طباعة / PDF بشكل رسمي، أو نسخ نص جاهز للواتساب، أو تصدير CSV.
5. **قائمة التسوق** — تحويل العرض لقائمة شراء مجمّعة **حسب المورد**، مع حالة كل صنف
   (لم يُطلب / تم الطلب / تم الاستلام) وحقل للتكلفة الفعلية.
   القائمة تحسب لك الفرق بين التقديري والفعلي، والربح الفعلي بعد الصرف.
   وفيه زر "نسخ طلبية المورد" يجهز لك نص ترسله للمورد مباشرة.

## كيف يُحسب السعر

```
سعر بيع الوحدة = تكلفة المورد × (1 + الهامش%)
إجمالي البنود  = مجموع (سعر الوحدة × الكمية)
قبل الضريبة    = إجمالي البنود + رسوم الخدمة + الشحن − الخصم
الإجمالي       = قبل الضريبة + ضريبة القيمة المضافة (15% افتراضياً)
ربحك           = قبل الضريبة − تكلفة الموردين
```

الافتراضيات (الضريبة، الهامش، رسوم الخدمة، صلاحية العرض) كلها من **الإعدادات**.

## البيانات — اقرأ هذا المهم

كل شيء محفوظ في **متصفحك أنت** (localStorage)، وهذا يعني:

- البيانات ما تنتقل بين الأجهزة، ولا يشوفها أحد غيرك.
- لو مسحت بيانات المتصفح أو غيّرت جهاز، تروح البيانات.
  ➜ نزّل **نسخة احتياطية** من الإعدادات بشكل دوري (ملف JSON)، والاسترجاع بضغطة.
- طلب العميل من النموذج **يُحفظ في متصفح العميل هو**، وما يوصلك تلقائياً.
  بعد الإرسال يطلع له زر "إرسال عبر واتساب" / "إرسال بالبريد" يوصلك الطلب جاهز منسّق.
  ➜ عشان تشتغل هذي الأزرار، عبّي **الجوال والبريد** في الإعدادات.

لو حبيت لاحقاً الطلبات توصلك تلقائياً في لوحة واحدة، هذا يحتاج طرف سيرفر
(نموذج مرتبط بقاعدة بيانات أو خدمة نماذج). الهيكل الحالي جاهز لهذي الإضافة.

## تغيير الاسم والهوية

الاسم والشعار والجملة التعريفية كلها من **الإعدادات** داخل الموقع — لو تبي
"جسر التجارة" بدل "جسر الحرير"، غيّر الحقل واحفظ.
والقيم الافتراضية موجودة في `assets/js/data.js` (`DEFAULT_SETTINGS`).

الأقسام والكتالوج الأولي كذلك في نفس الملف (`CATEGORIES` و `SEED_ITEMS`) —
الأسعار فيه **استرشادية**، عدّلها من تبويب "الأصناف" حسب أسعار موردينك.
